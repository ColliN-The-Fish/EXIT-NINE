# 第九出口 / EXIT NINE

复古第一人称单人恐怖游戏，当前玩家试玩版 v0.18.0 / UI6。包含三晚流程、中文字幕、合成角色配音和氛围配乐。玩家版无 F2 测试工具。

## 本地运行

建议 macOS + Chrome，使用键盘和鼠标。

```sh
npm start
```

然后打开 <http://127.0.0.1:4177/>。需要安装 Node.js；项目没有需要额外安装的 npm 依赖。

也可以双击 macOS 的 `启动玩家版.command`。不要直接通过 `file://` 打开 HTML。

## 文件

- `dist/`：完整静态网页及本地游戏资源。静态托管时以此目录为网站根目录。
- `server.mjs`：仅用于本地试玩的静态文件服务。
- `build-manifest.json`：构建文件及校验值。

此目录是玩家版，不包括开发测试工具、制作脚本、历史版本、测试截图和旧压缩包。上传仓库本身不会自动发布网页。

## 存档

进度自动保存在当前浏览器、当前网址的本地存储。更换域名或端口、无痕模式、清理网站数据不会保留原来的本地存档。浏览器本地存档不在仓库中。
